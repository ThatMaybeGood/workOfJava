## 三、项目结构与关键路径

- **后端**：Spring Boot 3 / Java 17 / MyBatis-Plus / H2（dev 模式，元数据库 `./data/etl_platform`）
  - 控制器：`com.etl.controller.*`（`api/etl/` 前缀）
  - 核心执行：`com.etl.service.core.{EtlEngine, PipelineExecutor, StepEngine, DataSourceManager, TaskScheduler}`
  - 抽取器：`com.etl.service.reader.{SqlReader, TableReader, ViewReader, ProcedureReader, HttpReader, FileReader, WebServiceReader}`
  - 写入器：`com.etl.service.writer.{InsertWriter, MergeWriter, FileWriter}`
- **前端**：`frontend/`（React + Vite，构建产物在 `src/main/resources/static/`）
  - 页面：`Datasource / Task / Mapping / Pipeline / Dashboard / Log / Settings`
- **种子数据**：`src/main/resources/db/h2_seed.sql`（`src_customer` 10 条、`src_order` 10 条、目标表 `tgt_customer`）
- **配置**：`application.yml`（端口 18880，dev profile）

## 四、常用命令

```bash
# 打包（含前端产物，前端已预构建到 static/）
mvn -q package -DskipTests

# 启动（后台，日志在 /tmp/etl-app.log）
rm -f data/etl_platform.trace.db
java -jar target/etl-platform-1.0.0-SNAPSHOT.jar --server.port=18880

# 停止（按端口杀进程）
netstat -ano | grep :18880 | grep LISTENING   # 拿 PID
taskkill //PID <pid> //F

# 启动 mock HTTP 服务（HTTP 抽取测试用，端口 18099）
python _mock_http.py
```

**注意**：重启前务必确保旧 JVM 完全退出（H2 文件库独占锁，否则报 90020 / 文件被占用）。用 `netstat -ano | grep :18880` 确认端口已释放再启动。
