# 门诊财务报表 — 功能描述与数据来源说明

## 一、功能描述

门诊财务报表面向门诊收费场景，按**月/天**两种粒度展示门诊量、缴费人次、收据张数、收入金额四项核心指标，支持**汇总/进项/退项**三种口径切换，全部图表随口径联动。

### 1. 筛选条件
- 时间范围（月模式为整月起止）
- 按月 / 按天（控制明细表与柱图的周期粒度）
- 汇总 / 进项 / 退项

### 2. 指标卡（顶部 4 张）
门诊量、缴费人次、收据张数、收入金额（元），各带**同比**。
同比 = 所选区间整体前移 12 个月的同期；(本期−同期)/同期，同期为 0 时显示 `--`。

### 3. 明细表与柱图
按周期列出四个指标的本期值、去年同期值、同比；柱图为本期 vs 同期的对比。

### 4. 分析图表（4 组 13 张，均带同期对比）
| 分组 | 图表 |
|---|---|
| 门诊量分析 | 订单来源分析、取号渠道分析、订单渠道分析 |
| 缴费人次分析 | 缴费人次渠道分析、支付方式金额分析 |
| 收据张数分析 | 渠道分析、支付方式金额分析 |
| 收入金额分析 | 业务类型金额分析、金额应收/实收分析、渠道分析、支付方式分析 |

「金额应收/实收分析」支持点击下钻：
- 点**应收账款** → 应收金额明细弹窗（按支付方式展开）
- 点**实收金额** → 实收金额明细弹窗

### 5. 悬浮标注
退项口径下，门诊量的悬浮提示展示**当日挂号退号**与**非当日退号**各多少。

## 二、数据来源

报表数据取自医院信息系统每日沉淀的业务数据：

| 数据 | 内容 |
|---|---|
| 挂号记录 | 每次挂号的日期、退号日期、是否退号、挂号费、诊查费、收费员 |
| 收据记录 | 每张收据的金额、退费关联、业务类别 |
| 结账记录 | 每位收费员每日结账的总金额、收据张数、退费张数（**收据张数/金额以此为准**） |
| 支付记录 | 每张收据的支付方式实收/退费金额 |
| 结账支付记录 | 每单结账按支付方式拆分的收入/退费金额 |
| 取号记录 | 患者取号来源（自助机、线上等） |

渠道统一归为三类：**自助机、线上退费、窗口**（按收费员归类）。

---

## 三、取值口径

### 1. 三种数据口径
- **进项**：所选周期内的全部发生数
- **退项**：所选周期内的退号/退费数
- **汇总 = 进项 − 退项**（净量）

### 2. 日期归属
- **门诊量的退项按退号日归属**（挂号与退号可能跨天：收留在挂号日、退量落在退号日）；某周期退多于进时为负数属正常
- 其余指标一律按挂号日/结账日归属

### 3. 人次合并
同一患者同一天、收据号码相连的多张收据，合并计为 **1 缴费人次**。

### 4. 应收/实收划分
- **医改统筹/医院垫支**：支付方式为医改统筹、医院垫支
- **实收金额**：支付宝、现金、信用卡、银行卡、微信、自助POS、支票
- **应收账款**：除以上外的其余支付方式

### 5. 业务类型分界（2025-02-08）
- 分界**之前**：当日挂号金额 = 挂号费 + 诊查费
- 分界**起**：按收据业务类别区分——挂号类收据计入当日挂号，其余计入门诊缴费

### 6. 指标与来源对照

| 指标/图表 | 数据来源 | 取值说明 |
|---|---|---|
| 门诊量 | 挂号记录 | 计数；退项为有效退号 |
| 缴费人次 | 收据记录 | 按人次合并规则计数；进项为正常收费，退项为退费收据 |
| 收据张数 | 结账记录 | 进项=收据张数，退项=退费张数，汇总=两者之差 |
| 收入金额 | 结账记录 | 进项=总费用，退项=退费金额，汇总=收入金额 |
| 订单来源分析 | 挂号记录 + 取号记录 | 按取号来源统计门诊量；无取号记录时按渠道归类 |
| 各渠道分析 | 挂号记录 / 收据记录 | 按自助机、线上退费、窗口统计门诊量或人次 |
| 支付方式金额分析 | 支付记录 / 结账支付记录 | 按支付方式汇总实收、退费金额 |
| 业务类型金额分析 | 挂号记录 + 收据记录 | 按第 5 条分界规则汇总当日挂号/门诊缴费金额 |
| 金额应收/实收分析 | 结账支付记录 | 按第 4 条三大类汇总 |
| 应收/实收金额明细弹窗 | 支付记录 | 按支付方式展开应收/实收明细 |
| 退项门诊量悬浮标注 | 挂号记录 | 当日退号 vs 跨日退号拆分 |
