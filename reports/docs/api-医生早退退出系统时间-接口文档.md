# 医生早退（退出系统时间）数据接口文档

> 需求方（我方）按日期向贵方请求医生当天退出系统时间的统计数据，由贵方计算后返回：按科室、医生、上下午维度，各医生退出系统时间、排班应结束时间及早退分钟数。
> 接口形态（HTTP 方式、鉴权）由贵方现有规范决定，本文只约定数据内容。

---

## 1. 需求指标

| # | 指标 | 说明 |
|---|------|------|
| 1 | 退出系统时间 | 指定日期当天，各医生 上午/下午 最后一次退出系统的时间 |
| 2 | 排班应结束时间 | 同维度下医生当天 上午/下午 排班的应结束时间 |
| 3 | 早退分钟数 | 排班应结束时间 − 退出系统时间，由贵方计算 |

日期由我方传入；维度为 **科室 → 医生 → 上/下午**。

## 2. 请求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | string | 是 | 查询日期，格式 `yyyy-MM-dd` |

## 3. 响应结构

按"医生 × 半天"返回，每条记录：

| 字段 | 类型 | 说明 |
|------|------|------|
| date | string | 日期 |
| dept_code | string | 科室编码 |
| dept_name | string | 科室名称 |
| doctor_code | string | 医生工号 |
| doctor_name | string | 医生姓名 |
| period | string | 时段：`AM`=上午，`PM`=下午 |
| schedule_end_time | string | 该半天排班应结束时间，格式 `yyyy-MM-dd HH:mm:ss` |
| last_logout_time | string | 该半天最后一次退出系统时间，格式同上；从未退出的给空值 |
| early_leave_minutes | number | 早退分钟数 = schedule_end_time − last_logout_time；未退出给空值，晚于排班结束退出给 0 |

## 4. 响应示例

```json
{
  "code": 0,                          // 状态码：0成功，非0失败
  "msg": "success",                   // 提示信息
  "data": {
    "date": "2026-10-12",             // 查询日期
    "records": [                      // 医生×半天 记录列表
      {
        "dept_code": "NK001",         // 科室编码
        "dept_name": "内科",           // 科室名称
        "doctor_code": "D1024",       // 医生工号
        "doctor_name": "张三",         // 医生姓名
        "period": "AM",               // 时段：AM=上午，PM=下午
        "schedule_end_time": "2026-10-12 12:00:00",   // 该半天排班应结束时间
        "last_logout_time": "2026-10-12 11:58:47",    // 该半天最后一次退出系统时间，从未退出给null
        "early_leave_minutes": 1                      // 早退分钟数=应结束时间-退出时间，未退出给null
      },
      {
        "dept_code": "NK001",
        "dept_name": "内科",
        "doctor_code": "D1024",
        "doctor_name": "张三",
        "period": "PM",
        "schedule_end_time": "2026-10-12 17:00:00",
        "last_logout_time": null,
        "early_leave_minutes": null
      }
    ]
  }
}
```

## 5. 口径约定（请贵方确认）

1. **退出系统时间**：取该半天内最后一次登出时间；若系统无登出日志（只关浏览器/自动超时），请告知实际数据来源及超时登出的记账时间。
2. **上下午划分**：以贵方排班系统的班次时段为准（上午班次结束 ≤ 14:00，下午 > 14:00）；若系统已有 AM/PM 标识，以系统为准并请说明。
3. **排班应结束时间**：请给"应下班时间"，而非"门诊停止挂号时间"。
4. **跨天退出**：当天未退出、次日才登出的，按未退出处理（last_logout_time 给空值，不计早退分钟数），但请保留该半天记录，便于区分"未退出"和"无排班"。
5. **当天未出诊**（无排班、无门诊）的医生可不传。
